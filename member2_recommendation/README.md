# Member 2: ALS Recommendation Engine
**Project:** Movie Recommendation System Using PySpark (MovieLens 32M)  
**Role:** Member 2 – Keerthana (Collaborative Filtering Recommendation Engine)  

---

## 1. Module Overview
This module implements an explicit-feedback collaborative filtering recommendation engine using Apache PySpark's Alternating Least Squares (ALS) algorithm on the MovieLens 32M dataset.

It takes the cleaned Parquet datasets generated by Member 1 (Anusree), performs a deterministic 80/10/10 data split, trains and regularizes the matrix factorization model, evaluates prediction accuracy using RMSE and MAE, generates Top-N personalized recommendations for active users (strictly excluding previously rated movies), and delivers production-ready integration artifacts for Member 3 (Hari)'s Streamlit dashboard and SQLite database.

## 5. Model Architecture & ALS Hyperparameters
- **Estimator Class:** `pyspark.ml.recommendation.ALS`
- **Feedback Type:** Explicit (`implicitPrefs=False`), minimizing squared loss on observed ratings.
- **Latent Embedding Dimension (`rank`):** 10 factors.
- **Regularization Parameter (`regParam`):** 0.1 ($L_2$ regularization penalty).
- **Optimization Iterations (`maxIter`):** 5 iterations.
- **Non-negative Factors:** `nonnegative=True` (Enforces $\mathbf{u}_u \ge 0$ and $\mathbf{v}_i \ge 0$).
- **Cold-Start Strategy:** `coldStartStrategy="drop"` (Drops unseen users/items during evaluation to prevent NaN metrics).
- **Reproducibility Seed:** `seed=42` across sampling, splitting, and weight initialization.

## 6. Model Serialization & Technical Limitations

### What is Persisted:
The model export located in `models/als_pilot_model/` contains:
1. `user_factors.parquet`: DataFrame of `id: int` (userId) and `features: list[float]` (latent embedding vector of length 10).
2. `item_factors.parquet`: DataFrame of `id: int` (movieId) and `features: list[float]` (latent embedding vector of length 10).
3. `metadata.json`: Model configuration parameters, timestamp, rank, and factor matrix row counts.

### Critical Serialization Note:
- **These files are factor matrix exports, NOT a complete reloadable PySpark `ALSModel`.**
- Calling `ALSModel.load()` or `ALSModel.load("models/als_pilot_model")` will **NOT** work.
- **Why?** Native PySpark `ALSModel.save()` relies on Hadoop's MapReduce `FileOutputCommitter`. On Windows NTFS filesystems, this committer throws `AccessDeniedException` when writing temporary metadata subfolders (`_temporary/0`).
- To ensure 100% cross-platform portability without brittle native OS hacks, factor matrices were exported as clean Parquet files.

### How to Compute Recommendations from Factor Matrices:
In Member 3's Streamlit dashboard or any standalone Python script, recommendations can be computed on the fly using standard linear algebra without needing a live Apache Spark cluster:
$$\hat{r}_{u,i} = \mathbf{u}_u \cdot \mathbf{v}_i = \sum_{k=1}^{10} u_{u,k} \cdot v_{i,k}$$
1. Read `user_factors.parquet` and `item_factors.parquet` via `pandas.read_parquet()`.
2. Extract the user vector $\mathbf{u}_u$ and compute dot products across all item vectors $\mathbf{V}$.
3. **Important:** Dot products alone do NOT exclude previously rated movies. To recommend only novel items, mask out or anti-join movies that the user has already rated in their rating history before sorting.
4. Sort remaining unrated movies descending by predicted score and take the Top $N$.

## 7. Recommendation Engine Corrections (Phase 3)

### Correction 1: Anti-Join Exclusion of Previously Rated Movies
- **Previous Defect:** Spark's native `recommendForUserSubset()` recommended movies across the entire catalog without filtering out items already rated by the user.
- **Resolution:** `generate_recommendations.py` generates an initial candidate pool of 100 items per user, executes a `left_anti` join against `train_ratings_df`, and assigns continuous ranks $1..10$ to the top unrated movies using a PySpark Window function ordered by `raw_score.desc(), movieId.asc()`.
- **Verification:** 100% of recommended movies for all 50 sample users are strictly unrated in their training history.

### Correction 2: Rating Value Handling (Raw vs Display Prediction)
- **Previous Defect:** Unconstrained ALS factor dot products can exceed the valid 0.5–5.0 star scale (e.g. 6.1, 10.6).
- **Resolution:**
  - `raw_prediction`: Preserves the authentic mathematical ALS dot product (rounded to 3 decimals).
  - `predicted_rating`: Formatted display rating clamped to $[0.5, 5.0]$ via `F.when(score > 5.0, 5.0).when(score < 0.5, 0.5).otherwise(score)`.
